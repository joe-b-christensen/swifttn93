The four real sets used in the SwiftTN93 preprint: public GenBank records, about 600 KB in all, xz-compressed FASTA.
Each has a matching .accessions.txt with the GenBank accession of every sequence in file order. Because the queries
below return different records over time, the accession lists are the record of what was used.

Downloaded on 11 October 2026 from NCBI nuccore via E-utilities (esearch + efetch, rettype=fasta).

1. HIV-1 pol (protease + first ~255 codons of reverse transcriptase)
   Query:  "Human immunodeficiency virus 1"[Organism] AND pol[Title] AND 1000:1600[SLEN] AND 2018:2026[PDAT]
           (182,294 hits; the first 9,000 records in NCBI's default order were fetched).
   Alignment: Nextclade 3.24.0, dataset community/neherlab/hiv-1/hxb2 (tag 2026-04-14--11-55-23Z), reference
           NC_001802 (HXB2). Insertions relative to the reference are removed (Nextclade's aligned FASTA), the
           standard HIV-TRACE practice of aligning to HXB2.
   Region: alignment columns 1795 to 2859, 0-based, inclusive (1,065 nt; NC_001802 coordinates, PR start ~1798).
   Filter: at least 800 non-gap, non-N nucleotides in the region -> 8,766 sequences.
           Subtype mix (Nextclade, all 9,000): B 3,785; A6 944; CRF07_BC 806; C 628; CRF01_AE 589;
           CRF08_BC 465; CRF02_AG 246; other 735.
   Split:  shuffled with random.Random(2026); first 5,000 -> real_hiv_pol_dev, remaining 3,766 ->
           real_hiv_pol_holdout.

2. SARS-CoV-2 complete genomes
   Query:  "Severe acute respiratory syndrome coronavirus 2"[Organism] AND "complete genome"[Title]
           AND 29000:30000[SLEN] AND 2024:2026[PDAT] (256,101 hits; first 1,000 fetched).
   Alignment: Nextclade 3.24.0, dataset nextstrain/sars-cov-2/wuhan-hu-1/orfs (tag 2026-09-07--17-10-15Z),
           reference MN908947 (Wuhan-Hu-1), 29,903 columns.
   Filter: Nextclade QC overall status "good" or "mediocre" -> 959 genomes
           (clades: mostly 25C, 26A, recombinants, 25E, 25B, 25H).
   Split:  shuffled with the same RNG; first 500 -> real_sars2_dev, remaining 459 -> real_sars2_holdout.

3. tn93's own test alignment (holdout h_real_tn93_large)
   data/large.fasta from github.com/veg/tn93 at commit 076eb0f (6,687 HIV-1 sequences, 2,841 columns). It is not stored
   here: prepare.py takes it from its clone of tn93. Provenance as documented upstream.

The scripts that made the four sets, for the record. Run today, the fetch returns different records and Nextclade's
latest datasets, so the output will differ from the files here:
  bash data/tools/fetch_real.sh realdata_raw
  python3 data/tools/make_real_data.py realdata_raw OUT_DIR

The simulated benchmark sets are generated by gen_data.py from fixed seeds when prepare.py runs.
